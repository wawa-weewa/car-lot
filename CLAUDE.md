# Автоплощадка

PWA для iPhone: учёт автомобилей на площадке, один пользователь. Интерфейс на русском, валюта ₪ (`CURRENCY` в `app.js`).

## Устройство
- Чистые HTML/CSS/JS без сборки и зависимостей: `index.html`, `styles.css`, `app.js`, `sw.js`, `manifest.webmanifest`, `icons/`.
- Данные в `localStorage`: авто в `carlot.v1`, сортировка и фильтр в `carlot.prefs`.
- Авто: `{ id, name, price, mileage, hand, engine, createdAt, updatedAt }`. Обязательно только `name`, числа целые или `null`. `hand` = «рука», 0 = новая.
- Функции: добавить, изменить и удалить (нажатие на карточку), сортировка (цена, название, пробег), фильтр «Цена до», поиск, выгрузка в CSV и JSON, загрузка из CSV и JSON (добавить к текущим или заменить).
- Импорт CSV сам определяет разделитель (`,` `;` таб), понимает русские, английские и иврит-заголовки, а также числа вида «62 000 ₪», «71,500», «88000 км».

## Дизайн
Палитра со скриншота пользователя (токены в `:root` в `styles.css`): plum `#2c1749`, berry `#ad2265`, pink `#ea1970`, blush `#ffa9cd`, lilac `#cecce2`, line `#615077`, фон `#f3f1f6`, тёмный фон `#1d1f30`. Есть светлая и тёмная тема.

## Правила
- При любом изменении файлов поднимать версию `CACHE` в `sw.js` (`carlot-vN`), иначе на iPhone останется старая версия.
- Сервис-воркер удаляет только кэши со своим префиксом `carlot-`: на `<логин>.github.io` рядом живёт другое приложение пользователя (`warehouse`).
- Публикация через GitHub Pages: публичный репозиторий `car-lot`, ветка `main`, папка `/ (root)`.
- Данные авто (CSV и JSON) не класть в репозиторий: он публичный.

## Локальный запуск
`python3 -m http.server 8081`. Для теста с iPhone нужен сервер с заголовком `Cache-Control: no-store`, иначе Safari держит старые файлы.
