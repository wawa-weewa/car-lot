# Автоплощадка

Веб-приложение (PWA) для учёта автомобилей на площадке. Работает на iPhone офлайн, данные хранятся на самом телефоне.

## Возможности
- Добавление авто: название, цена (₪), пробег, рука, двигатель
- Редактирование и удаление: нажмите на карточку
- Сортировка по цене (сначала дешевле), названию (А–Я) или пробегу (сначала меньше)
- Фильтр «Цена до»: своя сумма или готовые варианты
- Поиск по названию, общая стоимость машин на площадке
- Выгрузка в таблицу CSV (Excel, Numbers, Google Таблицы) и резервная копия JSON (меню «⋯»)
- Загрузка из CSV или JSON: можно добавить авто к текущим или заменить все
  Колонки таблицы: Название, Цена, Пробег, Рука, Двигатель. Обязательна только «Название».

## Запуск на компьютере
```sh
python3 -m http.server 8080
```
Откройте http://localhost:8080

## Публикация на GitHub Pages
1. Создайте на github.com **публичный** репозиторий `car-lot`.
2. Отправьте код:
   ```sh
   git remote add origin https://github.com/<ваш-логин>/car-lot.git
   git push -u origin main
   ```
3. **Settings → Pages → Deploy from a branch**, ветка `main`, папка `/ (root)`, затем **Save**.
4. Адрес приложения: `https://<ваш-логин>.github.io/car-lot/`

## Установка на iPhone
Откройте ссылку в **Safari**, нажмите «Поделиться» → **«На экран Домой»**.

## Обновление
После изменений увеличьте версию `CACHE` в `sw.js` (например, `carlot-v2`) и отправьте изменения на GitHub. Новая версия откроется после одного-двух перезапусков приложения. Данные при этом сохраняются.
